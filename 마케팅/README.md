# 마케팅팀

> 브랜드를 알리고, 고객을 모으고, 신뢰를 쌓는 팀

---

## 팀 미션

**"올바른 사람에게, 올바른 메시지를, 올바른 타이밍에"**

AI 제품의 가치를 시장에 정확히 전달하고, 잠재 고객이 우리를 발견하고 신뢰하도록 만드는 모든 활동을 담당합니다.

---

## 핵심 책임 영역

| 영역 | 내용 |
|------|------|
| 콘텐츠 마케팅 | 블로그, 뉴스레터, SNS 콘텐츠 기획 및 제작 |
| 브랜드 관리 | 브랜드 아이덴티티, 톤앤매너, 디자인 가이드 유지 |
| 성장 마케팅 | 유입 채널 관리, A/B 테스트, 전환율 최적화 (CRO) |
| 커뮤니티 & PR | 미디어 관계, 파트너십, 커뮤니티 운영 |
| 데이터 분석 | 마케팅 퍼포먼스 측정, KPI 대시보드 관리 |

---

## 핵심 KPI

| 지표 | 설명 |
|------|------|
| MQL (Marketing Qualified Lead) | 마케팅으로 유입된 잠재 고객 수 |
| CAC (Customer Acquisition Cost) | 고객 1명 획득 비용 |
| 유기 트래픽 | SEO를 통한 월간 방문자 수 |
| 콘텐츠 전환율 | 콘텐츠 방문 → 회원가입/문의 비율 |
| 브랜드 언급량 | 소셜/미디어 내 브랜드 노출 건수 |

## 콘텐츠 캘린더 & 운영 방식

### 콘텐츠 발행 주기
| 채널 | 주기 | 담당 |
|------|------|------|
| 공식 블로그 | 주 1회 | 콘텐츠 마케터 |
| LinkedIn | 주 3회 | 마케터 + 대표 |
| 인스타그램 | 주 2회 | 디자이너 + 마케터 |
| 뉴스레터 | 격주 | 콘텐츠 마케터 |

### 콘텐츠 제작 프로세스
```
기획안 작성 → 팀 리뷰 (2일) → 초안 작성 → 피드백 반영 → 발행 예약 → 성과 측정
```

### 캠페인 기획 주기
- **월간 캠페인**: 매월 마지막 주 금요일에 다음 달 계획 확정
- **분기 전략**: 분기 시작 2주 전 전략 리뷰 및 예산 배분

|------|----------|

| 커뮤니티 매니저 | SNS 운영, 미디어 관계, 파트너십 발굴 |

## 협업 원칙

1. **데이터 기반 의사결정** — 감이 아닌 수치로 캠페인 효과를 판단합니다.
2. **빠른 실험, 빠른 학습** — 작게 테스트하고 결과를 팀 전체와 공유합니다.
3. **브랜드 일관성** — 모든 채널에서 동일한 톤앤매너를 유지합니다.
4. **내부 고객 먼저** — 외부 발행 전 운영·개발팀과 내용을 공유합니다.
5. **저작권 준수** — 이미지·폰트·음원의 라이선스를 반드시 확인합니다.
